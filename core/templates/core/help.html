This database collects curated experiments on peptide-mediated RNA delivery from the literature.

How to use the database

Start on the browse page to search by experiment ID, paper title, DOI, PMID, peptide name, sequence, RNA target, or output text.

Use the RNA type, in vivo, and uptake confirmed filters to narrow the results.

Key fields

Experiment ID: unique identifier for one curated experimental record.

Paper ID: unique identifier for one publication; many experiments can belong to one paper.

Peptide ID: unique identifier for one peptide entry; many experiments can use the same peptide.

In vivo / Uptake confirmed: stored as yes, no, or blank when not clearly reported.

Noncanonical residues: shows named residue annotations such as ORN when present.

Missing values

Blank fields indicate information that was not reported, not curated yet, or could not be normalized confidently from the source paper.
