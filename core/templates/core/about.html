This resource is a curated database of peptide-mediated RNA delivery experiments collected from the published literature.

The current version focuses on linking each curated experiment to its paper, peptide, RNA context, formulation details, and reported outcome.

What is included

Each experiment record is linked to one paper and one peptide. Multiple experiments can come from the same paper, and multiple experiments can reuse the same peptide.

Curation approach

Data are curated from published articles into a structured spreadsheet and imported into the database. Numeric and boolean fields are normalized where possible, while ambiguous or unavailable values are left blank.

Access

This database is intended to be freely accessible for browsing and literature-based exploration.
